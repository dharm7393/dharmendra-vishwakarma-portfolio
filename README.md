# Dharmendra Vishwakarma — Portfolio

A modern, high-performance single-page developer portfolio showcasing full-stack web applications, technical skills, and software engineering experience.

**Live site:** https://dharmendra-vishwakarma-portfolio.vercel.app/

---

## Tech Stack

- **Frontend Library:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion & AOS (Animate On Scroll)
- **Email Service:** EmailJS (@emailjs/browser)
- **Interactive Visuals:** WebGL (SplashCursor fluid simulation)

---

## Run Locally

Clone the repository and install dependencies:

```bash
# Clone repository
git clone https://github.com/dharm7393/dharmendra-vishwakarma-portfolio.git
cd dharmendra-vishwakarma-portfolio

# Install packages
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

---

## Environment Variables

Create a `.env.local` file in the root directory to enable the interactive contact form:

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```
